Work through these tasks after each lesson.

{{% steps %}}

### Choose a dataset

Pick a small public tabular dataset, for example the UCI Adult dataset. Split it into a training set and a held-out test set.

### Train a generator

Train a GAN on the training set with the code from [Lesson 2.1](../02-generative-models/gans/). Generate as many synthetic rows as there are real training rows.

### Evaluate the result

Apply the TSTR protocol from [Lesson 3](../03-evaluation/). Report the accuracy gap between the real-trained and the synthetic-trained classifier.
